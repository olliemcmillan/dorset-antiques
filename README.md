# Dorset Antiques

A private collection website for glassware, fine art and furniture. Built with [Astro](https://astro.build) on the [Mast for Astro](https://github.com/CoreyMoen/mast-astro) starter, and hosted on Cloudflare Workers.

```sh
npm install
npm run dev
npm run build
npm run deploy
```

Requires Node 22.12 or newer.
